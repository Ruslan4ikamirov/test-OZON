Прототип блока Progress с применением HTML, JS и препроцессора SCSS.
Структура проекта:
1. Папка css с файлом index.css, подключаемым к нашей HTML-странице, в который компилируются все стили, написанные на SCSS
2. Папка scss, включающая в себя итоговый файл index.scss, преобразуемый в файл css-стилей и 3 папки:
   - reset (для сброса некоторых свойств, по умолчанию устанавливаемых браузером)
   - mixins(для написания повторяемых стилей и их многократной используемости в файлах)
   - components (для создания отдельных стилевых модулей для конкретных элементов приложения)
3. Папка scripts, содержащая файл script.js, подключаемый к HTML, в который импортируются все остальные JS-модули; папка modules с отдельными функциями:
   - validateValue - функция, обеспечивающая корректность значения, вводимого в поле value (от 0 до 100)
   - updateProgress - функция, подсчитывающая длину дуги в соответствии с введённым значением
   - spinProgress - функция для управления вращением нашей дуги
   - hideProgress - функция для скрытия элемента Progress со страницы
4. Папка assets - для хранения изображений и иконок, в моем случае для хранения иконки, отображаемой в браузере рядом с названием страницы
